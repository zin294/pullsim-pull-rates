# Sources

Each set's rates come from one published TCGplayer Authentication Center pack-opening study.

- Ascended Heroes — 2,000 packs — https://www.tcgplayer.com/content/article/Pok%C3%A9mon-TCG-Ascended-Heroes-Pull-Rates/60143d94-88a7-42ce-8e73-babd7b3fabd6/
- Prismatic Evolutions — 1,200 packs — https://www.tcgplayer.com/content/article/Pok%C3%A9mon-TCG-Prismatic-Evolutions-Pull-Rates/d94889ea-f76a-4a13-b74d-5b0b071220a7/
- Phantasmal Flames — 5,000 packs — https://www.tcgplayer.com/content/article/Pok%C3%A9mon-TCG-Phantasmal-Flames-Pull-Rates/9abae60d-b7fb-448f-874e-176f78d6a6ca/
- Delta Reign — no English sample published as of 2026-10-30

All figures are reproduced from those studies without adjustment. Card records (names,
identifiers, artwork) come from TCGdex and never determine a tier rate.

If a figure is updated upstream, this repo will change the rate and the date, and — where
the old value is still reported somewhere in the source — keep it as `alternateRatePct`.
